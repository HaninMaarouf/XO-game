# 🎮 XO Game

A simple and interactive **XO (Tic-Tac-Toe) game** built using **HTML, CSS, and JavaScript**.

The game allows two players to play XO on a 3×3 board, automatically detects winning combinations, highlights the winning cells, and announces the winner.

## ✨ Features

* 🎮 Two-player gameplay
* ❌ X and ⭕ O turn switching
* 🏆 Automatic winner detection
* 💡 Highlights the winning combination
* 🔄 Automatically resets after a winner is detected
* 📱 Responsive design for different screen sizes
* ✨ Modern glassmorphism-style interface
* 🌈 Purple and blue gradient background
* 🖱️ Interactive hover effects

## 🛠️ Technologies Used

* **HTML5** — Structure of the game
* **CSS3** — Styling, responsive design, gradients, and animations
* **JavaScript** — Game logic, player turns, and winner detection

## 🎯 How to Play

1. The game starts with **X**.
2. Click any empty square to place your symbol.
3. Players take turns between **X** and **O**.
4. The first player to get **three matching symbols in a row** wins.
5. Winning combinations can be:

   * Horizontal
   * Vertical
   * Diagonal
6. The winning cells are highlighted.
7. The game automatically restarts after the winner is displayed.
